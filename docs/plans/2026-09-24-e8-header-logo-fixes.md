# E8 — меню сайту, Hero на весь екран, логотип з адмінки, дрібні правки

Зауваження власника до лендингу після E7 (2026-09-24) і його відповіді на
уточнення.

## Рішення власника

1. **Меню в хедері**: «Натальна карта» (`/natal`), «Можливості»,
   «Тарифи», «Як це працює» (якорі на лендингу); праворуч «Увійти» і
   «Реєстрація», а для того, хто вже увійшов, замість них одна кнопка
   «Мій кабінет». Хедер **завжди вгорі** (fixed); на Hero він прозорий, після
   прокрутки отримує напівпрозорий темний фон. На мобільному — кнопка-бургер
   і панель.
2. **Перенаправлення `/` → `/dashboard` для того, хто увійшов, прибирається**
   — інакше «Мій кабінет» на лендингу ніхто б не побачив. `/login` і
   `/register` і далі перенаправляють.
3. **Hero** — висотою в екран (`100svh`), унизу анімована стрілка до
   наступної секції. При `prefers-reduced-motion` стрілка не рухається.
4. **Логотип з адмінки — два**: для темного фону (вітрина) і для світлого
   (дашборд). Порожнє поле = текстовий «Astrodite», як зараз. PNG, JPEG,
   WebP; SVG і ICO — ні (SVG з нашого домену = stored XSS, як і для favicon).
5. **Дашборд**: бічна панель на десктопі — висотою в екран і не прокручується
   разом зі сторінкою (`sticky top-0 h-screen`).
6. **Колесо**: підписи ASC/DSC налазять на зовнішнє коло — центровані на
   радіусі R_OUTER+14 при ширині ~30 px. Вирівнювати від кінця променя
   назовні (`text-anchor` end/start), а не по центру.

## Результат перевірки (2026-09-24, локально)

- Лендинг 1280×800: Hero = 800 px, стрілка анімується й веде до «фактів»;
  хедер прозорий над Hero, після прокрутки — `space-950/85` з blur.
  «Тарифи», «Як це працює» (у т. ч. з `/natal`) і стрілка ставлять секцію
  рівно під хедер (64 px).
- 375 px: бургер відкриває панель (`aria-expanded`), закривається кнопкою,
  Escape і кліком на пункт; горизонтального скролу немає; Hero = 812 px.
- Залогінений: `/` більше не перекидає в дашборд; у хедері й Hero —
  «Мій кабінет» → `/dashboard`.
- Логотипи: завантажені через API тестові PNG показуються на вітрині (темний)
  і в дашборді (світлий); в адмінці прев'ю на відповідному фоні; видалення
  через форму повертає текстовий «Astrodite» і прибирає файли з диска.
- Дашборд: на сторінці 6838 px бічна панель — 0..800 px, «Вийти» видно.
- Колесо: ASC/DSC цілком поза зовнішнім колом (~10 px відступу).
- `prefers-reduced-motion`: анімація стрілки й плавна прокрутка існують
  лише в `@media (prefers-reduced-motion: no-preference)` — перевірено за
  згенерованим CSS (емулювати медіазапит у цьому браузері не можна).
- pytest 228 passed, npm test 12/12, tsc, build — чисті; консоль чиста.
