# Підключення оплат: monobank і Stripe — покрокова інструкція

Складено 2026-09-24. Код обох інтеграцій уже готовий і працює на сервері —
бракує лише облікових записів і ключів. Стан на сервері зараз:
`MONOPAY_TOKEN`, `STRIPE_SECRET_KEY`, `STRIPE_WEBHOOK_SECRET`,
`STRIPE_PRICE_PRO_MONTHLY`, `STRIPE_PRICE_PRO_YEARLY` — **порожні**.
`API_PUBLIC_URL=https://api.astrodite.cc` і `FRONTEND_URL=https://astrodite.cc`
— правильні.

> **Безпека.** Ключі вводите тільки ви, у свій термінал. Не надсилайте їх у
> чат, пошту чи месенджери. Єдине, що можна спокійно передати мені, — ID цін
> Stripe (`price_…`): це не секрет.

## Спершу головне: що реально можна підключити

| | monobank | Stripe |
|---|---|---|
| Хто може | ФОП або юрособа в Україні з рахунком у monobank | **Лише компанія в країні, яку підтримує Stripe.** Україна в списку [stripe.com/global](https://stripe.com/global) **відсутня** |
| Валюта оплати | гривня (ми показуємо $ і ≈ ₴) | долар |
| Автопродовження | немає (разовий платіж: 30 або 365 днів) | є (щомісяця або щороку) |
| Скільки часу | заявка ~10 хв + перевірка сайту | реєстрація компанії за кордоном — тижні |

**Рекомендований порядок:** спочатку monobank (частини 0–2), Stripe — коли
буде рішення про компанію (частина 3). До того кнопки Stripe на сайті
треба сховати — див. «Що зробити в коді» наприкінці.

## Частина 0. Підготувати сайт до перевірки monobank

monobank перед підключенням інтернет-еквайрингу дивиться на сайт. Його
вимоги ([monobank: підключення еквайрингу](https://monobank.ua/en/knowledge-base/acquiring/signup)):
робочий дизайн і посилання, діяльність відповідає реєстрації, українська
версія, інформація про компанію, контакти, товари/послуги з описом і цінами.

| Вимога | Стан |
|---|---|
| Українська версія | ✅ |
| Контакти | ✅ info@astrodite.cc (телефон — на ваш розсуд) |
| Послуги з описом і цінами | ✅ блок «Тарифи» |
| Інформація про компанію | ❌ **ніде немає даних ФОП** |
| Умови / оферта | ⚠️ сторінки `/terms` і `/privacy` мають видимий напис **«Чернетка»** |

**Що зробити:**
1. Дайте мені дані ФОП для сайту: **ПІБ ФОП** і **РНОКПП** (так роблять
   більшість українських сервісів; адресу — лише якщо хочете). Я додам їх у
   футер і на сторінку умов.
2. Вичитайте `/terms` і `/privacy` (ідеально — з юристом). Коли тексти
   погоджено, я приберу позначку «Чернетка».
3. Перевірте, що ваш КВЕД підходить під продаж онлайн-сервісу
   (наприклад 62.01, 63.12) — це видно в monobank у даних ФОП.
4. **ПРРО / фіскальні чеки.** Для оплат карткою на сайті можуть бути
   потрібні фіскальні чеки. Це питання до вашого бухгалтера, не до коду.
   monobank має власні інструменти фіскалізації — запитайте про них у
   підтримці, якщо бухгалтер скаже, що чеки потрібні.

## Частина 1. Підключити інтернет-еквайринг monobank

1. **Рахунок ФОП у monobank.** Якщо його ще немає: застосунок mono →
   відкрити рахунок ФОП (кілька хвилин).
2. Увійдіть у бізнес-кабінет **[web.monobank.ua](https://web.monobank.ua/)**.
3. Ліворуч — **«Додати інструмент»** → оберіть оплату на сайті
   (інтернет-еквайринг).
4. Заповніть дані про бізнес:
   - сайт: `https://astrodite.cc`
   - опис: «Онлайн-сервіс астрологічних розрахунків (натальні карти,
     транзити, соляри, синастрії). Підписка Pro — доступ до розширених
     розрахунків на 1 місяць або 1 рік.»
5. **Підтвердіть заявку в застосунку mono** — з номера телефону, до якого
   прив'язаний ФОП.
6. Дочекайтеся схвалення (зазвичай швидко; якщо сайт не пройде перевірку —
   напишуть, що виправити; перешліть мені).

## Частина 2. Отримати токен і вставити на сервер

**Отримати токен** ([monobank: як отримати токен](https://monobank.ua/knowledge-base/acquiring/online/website/platforms/token)):
1. [web.monobank.ua](https://web.monobank.ua/) → вкладка **«Оплата на
   сайті»** → **«Налаштувати»**.
   (Пізніше це місце — **«Інтеграції» → «На мій сайт»**.)
2. Створіть токен і скопіюйте його.

**Вставити на сервер** (у вашому терміналі):

```bash
ssh -i ~/.ssh/hermes_remote_key deploy@37.60.229.175
```

```bash
sudo nano /opt/zorya/infra/.env
```

- Знайдіть рядок `MONOPAY_TOKEN=` і вставте токен одразу після `=`, без
  пробілів і лапок. **Вставляйте один раз** — текст буде видно на екрані,
  перевірте, що він не задвоївся.
- Збережіть: `Ctrl+O`, `Enter`. Вийдіть: `Ctrl+X`.

Перезапустити API, щоб він прочитав новий `.env`:

```bash
cd /opt/zorya/infra && sudo docker compose up -d --force-recreate api
```

Перевірити, що ключ на місці (показує лише «set»/«EMPTY», не сам ключ):

```bash
sudo grep -E '^(MONOPAY_TOKEN|STRIPE_[A-Z_]+)=' /opt/zorya/infra/.env | awk '{k=substr($0,1,index($0,"=")-1); v=substr($0,index($0,"=")+1); print k": "(v==""?"EMPTY":"set, "length(v)" символів")}'
```

**Вебхук налаштовувати не треба**: наш сервер сам передає monobank адресу
`https://api.astrodite.cc/api/v1/billing/monopay/webhook` у кожному рахунку.

### Перевірка живим платежем (обов'язково)

У monobank немає тестових карток, тому перевіряємо реальною оплатою:
1. Увійдіть на astrodite.cc **другим** акаунтом (не адмінським) →
   **Тарифи** → **Pro щомісяця** → «Оплатити через monobank (UAH)» →
   сплатіть 350 ₴ своєю карткою.
2. Після повернення на сайт: **Оплата** має показати «Pro» і «Активний до
   …». Бейдж у шапці — Pro.
3. Скажіть мені — я перевірю на сервері запис платежу й підписки.
4. За бажанням поверніть гроші в [web.monobank.ua](https://web.monobank.ua/)
   (повернення платежу). Наш сервер отримає статус `reversed` і поверне
   акаунт на Free — це теж перевірка.

Лише після цього оголошуйте оплату публічно.

## Частина 3. Stripe

### 3.1. Рішення: як отримати акаунт Stripe

Український ФОП бойовий акаунт Stripe відкрити не може. Варіанти:

1. **Не підключати зараз.** monobank покриває Україну; кнопки Stripe
   ховаємо (див. нижче). Рекомендую почати з цього.
2. **Компанія в країні, яку підтримує Stripe** (наприклад, Польща чи
   Естонія через e-Residency) — потрібні реєстрація, місцевий бухгалтер,
   податки там.
3. **[Stripe Atlas](https://stripe.com/atlas)** — реєстрація американської
   компанії (Delaware) через Stripe. Доступний для громадян України, крім
   жителів Криму, Донецької й Луганської областей (санкційні обмеження).
   Має разову вартість і щорічні витрати (агент, податкова звітність у
   США) — оцініть з бухгалтером.
4. **Сервіс-посередник** (merchant of record, наприклад Paddle) — він
   продає від свого імені й сам сплачує податки. Потребує окремої
   інтеграції в коді й перевірки, чи працює з Україною.

Це рішення — ваше і вашого бухгалтера. Коли буде акаунт Stripe, йдіть далі.

### 3.2. Налаштування акаунта Stripe (коли він є)

Спочатку все робиться в **тестовому режимі** (перемикач «Test mode» у
кабінеті), потім повторюється в бойовому.

1. **Продукт і ціни** — **Product catalogue** → **Add product**:
   - Name: `Astrodite Pro`
   - Price: **Recurring**, **$9.00 USD**, **Monthly** → Save.
   - На сторінці продукту → **Add another price**: **Recurring**,
     **$99.00 USD**, **Yearly** → Save.
   - Скопіюйте ID обох цін (`price_…`) — їх можна надіслати мені.
2. **Ключ API** — **Developers → API keys** → **Secret key** → Reveal →
   скопіюйте (`sk_test_…` у тестовому, `sk_live_…` у бойовому).
3. **Вебхук** — **Developers → Webhooks** → **Add endpoint**:
   - URL: `https://api.astrodite.cc/api/v1/billing/stripe/webhook`
   - Events: `checkout.session.completed`,
     `customer.subscription.created`, `customer.subscription.updated`,
     `customer.subscription.deleted`, `invoice.payment_succeeded`
   - Після створення → **Signing secret** → Reveal → скопіюйте (`whsec_…`).
4. **Customer Portal** — **Settings → Billing → Customer portal**:
   - увімкнути скасування підписки;
   - **Customers can switch plans** → додати `Astrodite Pro` з обома цінами
     (щоб місячні могли перейти на річну й назад);
   - посилання на умови та конфіденційність:
     `https://astrodite.cc/terms`, `https://astrodite.cc/privacy`.
5. **Бренд і методи оплати** — **Settings → Branding** (логотип, колір);
   **Settings → Payment methods** — увімкніть Apple Pay / Google Pay.
6. **На сервер** — так само, як для monobank (`sudo nano
   /opt/zorya/infra/.env`), заповніть:
   ```
   STRIPE_SECRET_KEY=sk_...
   STRIPE_WEBHOOK_SECRET=whsec_...
   STRIPE_PRICE_PRO_MONTHLY=price_...
   STRIPE_PRICE_PRO_YEARLY=price_...
   ```
   Потім перезапуск API й перевірка — ті самі дві команди, що в частині 2.
7. **Перевірка в тестовому режимі** — на сайті Pro → «Підвищити карткою»,
   картка `4242 4242 4242 4242`, будь-яка майбутня дата, будь-який CVC.
   Після оплати **Оплата** показує Pro. Скасуйте в «Керувати підпискою» —
   після кінця періоду акаунт повернеться на Free.
8. **Перехід у бойовий режим** — повторіть кроки 1–6 з вимкненим «Test
   mode»: тестові ціни, ключ і вебхук у бойовому режимі не існують, усі
   ID будуть нові. Потім одна справжня оплата й повернення.

## Що зробити в коді (моя частина)

- **Зараз на продакшені кнопки оплати видно, хоча ключів немає** — клік
  показує помилку. Треба ховати кнопку провайдера, доки він не
  налаштований, і показувати «Оплата скоро буде доступна».
- Дані ФОП у футері й на сторінці умов — коли надішлете.
- Прибрати «Чернетка» з `/terms` і `/privacy` — коли тексти погоджено.
